# 📝 Todo App with Authentication & Routing

Клієнтський вебдодаток для керування повсякденними задачами із вбудованою системою авторизації користувачів, динамічним роутингом та збереженням даних у браузері.

Проєкт реалізовано без використання зовнішнього бекенду: вся логіка авторизації, перевірка доступу та збереження стану задач виконуються на стороні клієнта за допомогою `localStorage`.

---

## ✨ Ключові можливості

### 🔐 Авторизація та безпека
* **Реєстрація та логін:** Форми входу й реєстрації з клієнтською валідацією полів.
* **Захищені маршрути (Protected Routes):** Доступ до головної сторінки та деталей задач відкритий лише для авторизованих користувачів. Неавторизованих користувачів автоматично перенаправляє на `/login`.
* **Збереження сесії:** Залогінений користувач залишається в системі навіть після оновлення сторінки.
* **Вихід із системи (Logout):** Можливість завершити поточну сесію.

### 📋 Управління задачами (CRUD)
* **Створення задач:**Швидке додавання нових задач.
* **Керування статусом:** Перемикання стану задачі (*Активна* / *Виконана*).
* **Видалення:** Вилучення непотрібних задач зі списку.
* **Фільтрація та пошук:** Пошук задач за назвою та фільтрація за статусом (*Усі*, *Активні*, *Виконані*).

### 🔗 Детальні сторінки та роутинг
* **Динамічні URL-параметри:** Окрема сторінка для кожної задачі (`/todo/:id`).
* **Синхронізація стану:** Зміна статусу задачі на детальній сторінці негайно відображається в загальному списку.
* **Обробка помилок (404):** Інформування користувача або редірект у разі спроби відкрити задачу з неіснуючим `id`.

### 💾 Збереження даних
* Автоматична синхронізація списку задач та стану користувача з `localStorage`.

---

## 🛠 Технологічний стек

* **Frontend:** React, TypeScript / JavaScript
* **Роутинг:** React Router (`BrowserRouter`, `Routes`, `Route`, `Navigate`, `useParams`)
* **Робота з формами:** React Hook Form
* **Збереження даних:** `localStorage` API
